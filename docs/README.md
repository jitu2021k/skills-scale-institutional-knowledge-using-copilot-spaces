# OctoAcme Project Management Documentation

## Overview
Welcome to OctoAcme's project management documentation. This repository centralizes our approach to running projects, managing teams, and delivering customer value.

## Purpose
These documents provide clear guidance on:
- How we initiate and plan projects
- How we execute and track progress
- How we manage risks and communicate status
- How we release features and iterate
- The roles and responsibilities within project teams

## OctoAcme Project Management Processes

Our approach is built on these core principles:
- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has named roles and accountability
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and continuous learning

## Quick Start for New Team Members

1. **Start with the [Project Management Overview](docs/octoacme-project-management-overview.md)** to understand our approach and key roles
2. **Review the [Roles & Personas](docs/octoacme-roles-and-personas.md)** to understand your role and others'
3. **For your current project phase**, refer to the relevant process guide (Initiation, Planning, Execution, Release, or Retrospective)
4. **Use the templates and checklists** in each document to guide your activities
5. **Ask questions** — our process is designed to support collaboration and learning
